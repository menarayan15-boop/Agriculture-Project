📱 SMS Commands

Send these texts to +91-XXXXXXXXXX

SMS: STATUS
→ Gets soil moisture, weather, pump state
SMS: PUMP ON
→ Turns on irrigation pump
SMS: PUMP OFF
→ Turns off irrigation pump
SMS: HEALTH
→ Gets heart rate, temp, SpO₂, hydration
SMS: ALERT
→ Gets current risk level + advice

📟 USSD Code

Dial from any keypad phone (no internet needed):

*920*FARM#
1 → Farm Status
2 → Pump Control
3 → Health Check
4 → Weather
5 → Emergency SOS
